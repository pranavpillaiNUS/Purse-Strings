# Planned bounded CLI shopper (M4)

No model integration is implemented in this scaffold. First prove the rules and ledger
with explicit CLI inputs. Later expose only catalog search, product view and price-free
cart submission tools to a separate worker. Model output drafts a mandate; the local
operator reviews and confirms it through CLI I/O before any execution.

No payment credentials, payment tools, policy writes, shell tools or arbitrary URL
fetching. Bound tool calls and model spend. Keep hostile catalog prose as data. The
trusted executor loads quotes and ledger state independently. See `AGENTS.md`.
